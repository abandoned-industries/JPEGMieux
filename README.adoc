= JPEGMieux 3.0

A fast, keyboard-driven slideshow viewer for big photo and video collections on the Mac. Native on Apple Silicon and Intel, macOS 12 or later.

image::JPEGMieux-icon.png[JPEGMieux icon,256]

== Why this exists

I browse large photo archives: tens of thousands of images in nested folders on an external drive. For that job I want a viewer that opens a whole folder tree, puts the pictures up full screen, and lets me move through them from the keyboard without importing anything into a library. JPEGDeux did exactly that for years. Then macOS moved on and it stopped running. Nothing current does it quite the same way, so I brought it back.

== A short history

*JPEGView (1990s).* Aaron Giles wrote JPEGView for the classic Mac OS. It was the fast, free image viewer many Mac users relied on, and its icon was a glossy red ball with a blue "j".

*JPEGDeux (2001).* When Mac OS X arrived, Peter Ammon wrote JPEGDeux as its successor: "deux" because it was the second one. He dedicated it to Aaron Giles and JPEGView, and kept it going on SourceForge through the mid-2000s. The project went quiet, and the last builds stopped working after Mac OS X 10.6.

*Terrence Curran's revival (2011–2022).* Terrence Curran forked JPEGDeux, got it building and running again on OS X 10.7 and 10.8, and published new builds in 2013. In 2016 he started adding tests ahead of a larger cleanup that never happened.

*Why it broke again.* The code still carried pieces from the early 2000s: QuickTime, which Apple removed along with 32-bit apps; hand-written assembly for old processors; and interface files and system calls that current Xcode no longer accepts. By the Apple Silicon era it would not build or run.

*JPEGMieux (2025–26).* This fork rebuilds it for current Macs. QuickTime is replaced with AVFoundation, so videos play alongside photos. The old code is cleaned up until the build is warning-free apart from one deliberate exception. The file list shows your folders and subfolders. The rebuild was done with Claude Code, Anthropic's AI coding tool, with me testing on my own collection and deciding what stayed.

*The name.* JPEGView, then JPEGDeux, then JPEGMieux. "Mieux" is French for "better", and it is also roughly what a cat says. The cat on the icon is Ajman, peeking out from behind the JPEGView ball where the "2" used to be.

== Features

* Full-screen and windowed slideshow modes
* **Video playback support** (MP4, MOV, M4V, AVI, and more)
* Multiple transition effects (crossfade, scroll, etc.)
* Modern card-based UI layout
* Quick file picker panel during slideshow (Tab key)
* Movies-only filter option
* Customizable keybindings for slideshow control
* Image sorting (by name, date modified, date created, or number)
* Hierarchical folder support with drag and drop
* Custom background colors
* Smart image caching for improved performance
* High-quality image upscaling with trilinear filtering
* Support for animated GIFs
* JPEG comment display
* Online image sequence support

== Keyboard Shortcuts (During Slideshow)

|===
|Key |Action

|Right Arrow |Next image/video
|Left Arrow |Previous image/video
|Space |Toggle auto-advance
|Tab |Toggle file list panel
|P |Cycle filename display
|Escape / Cmd+. |End slideshow
|===

== Changes in Version 2.0

=== New Features

==== Video Playback Support
* Play MP4, MOV, M4V, AVI, and other video formats in slideshows
* Video playback controls during slideshow
* Automatic skipping of unplayable video files
* Movies-only filter to show only video files

==== Modern UI
* New programmatic card-based UI layout
* Larger main window with better organized controls
* Quick file picker panel (Tab key) for jumping to specific files during slideshow
* Cleaner preferences and menu structure

==== Performance Improvements
* Smart image caching for smoother slideshows
* Trilinear filtering for high-quality image upscaling
* Better memory management

=== Code Modernization

==== Apple Silicon & Modern macOS Support
* Native Apple Silicon (M1/M2/M3) support
* Requires macOS 12 or later (3.0)
* Updated to Xcode 15 project settings

==== Swift 5 Compatibility
* Modernized enums for Swift 5 interoperability
* Updated test suite for Swift 5

==== Deprecated API Cleanup
* Removed deprecated Carbon framework imports
* Removed deprecated ApplicationServices imports
* Replaced `useOptimizedDrawing` (deprecated)
* Fixed `NSEvent` context deprecations
* Updated `NSArchiver` to handle legacy preferences format
* Fixed framework paths for modern macOS SDK

=== Removed Features

The following legacy features were removed as they no longer work on modern macOS:

* **Force Fit scaling option** - Removed from UI
* **QuickTime-based shows** - Replaced with AVFoundation
* **Direct Display show mode** - No longer supported
* **Image rotation/flipping** - Keyboard shortcuts removed
* **Move to Trash** - Keyboard shortcut removed
* **Move/Copy to folder** - Keyboard shortcuts removed
* **Deprecated preferences** - Removed non-working options

=== Bug Fixes

* Fixed crash on nil color when loading legacy preferences
* Fixed file list clicking wrong item by using file paths instead of indices
* Fixed Scaling card being hidden by overlapping Playback card
* Fixed slideshow window not closing properly
* Fixed scaling options migration from old preferences
* Fixed image scaling calculations in BackgroundImageView
* Fixed app crash on startup with corrupted preferences

== Building

Requirements:

* Xcode 15 or later
* macOS 12+ SDK

To build:

1. Open `JPEGDeux.xcodeproj` in Xcode
2. Select your signing team in project settings
3. Build (Cmd+B) or Run (Cmd+R)
